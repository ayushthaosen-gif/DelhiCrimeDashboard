Import-ready production data for 2022. Start with `manifest.json`; it contains source URLs, checksums, coverage and null/comparability rules.

Files:
- `district_crime.json` - delhi_district_crime_2022
- `district_crime.csv` - delhi_district_crime_2022
- `district_road_safety.json` - delhi_district_road_safety_2022
- `district_road_safety.csv` - delhi_district_road_safety_2022
- `citywide_road_safety.json` - delhi_citywide_road_safety_2022
- `citywide_road_safety.csv` - delhi_citywide_road_safety_2022

Null values are never zeros. Infrastructure is catalogued in `../shared/manifest.json` because it is not a same-year historical measurement.
