# Delhi research release 2020

Import-ready production data for 2020. Start with `manifest.json`; it contains source URLs, checksums, coverage and null/comparability rules.

Files:
- `district_crime.json` - delhi_district_crime_2020
- `district_crime.csv` - delhi_district_crime_2020
- `citywide_road_safety.json` - delhi_citywide_road_safety_2020
- `citywide_road_safety.csv` - delhi_citywide_road_safety_2020

Null values are never zeros. Infrastructure is catalogued in `../shared/manifest.json` because it is not a same-year historical measurement.
