# Data directories

- Files directly under `data/` are inputs or derived datasets consumed by the published dashboards.
- `data/source/` contains reproducibility inputs that are not dashboard outputs.
- `data/releases/2025/` is the audited 2025 research release, including raw-source copies, validated partial datasets, review queues, and provenance.

Reusable dashboard-independent CSV and JSON outputs remain under the top-level `exports/` directory.
